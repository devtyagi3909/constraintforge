# Cmod A7-35T

**Device:** XC7A35T-1CPG236C | **Vendor:** Digilent

**Covered:** **12 MHz clock** (not 100 MHz!), RGB LED, 1 green LED, 2 buttons, USB-UART, 44 DIP header pins (PIO1–PIO44).

> ⚠️ **12 MHz oscillator** — period = 83.333 ns. Many designs require an MMCM to generate higher frequencies.

Designed for breadboard insertion (DIP-48 form factor). Extremely popular for portable/standalone projects.
