# Nexys A7-100T

**Device:** XC7A100T-1CSG324C | **Vendor:** Digilent

**Covered:** 100 MHz clock, 16 switches, 16 LEDs (+ 2 RGB), 8-digit 7-segment, 5 buttons, USB-UART, VGA, Gigabit Ethernet (RGMII), PDM microphone, PWM audio, Pmod JA/JB/JC/JD.

> This is the most widely used university FPGA board worldwide. If you're doing a course project, this is probably your board.
