# Boolean Board

**Device:** XC7A35T-1CPG236C | **Vendor:** Real Digital

**Covered:** 100 MHz clock, 16 switches, 16 LEDs, 4-digit 7-segment, 5 buttons, USB-UART, VGA.

Purpose-built for digital logic education. The Boolean board uses the same XC7A35T as the Basys3 — pin assignments for switches, LEDs, 7-segment, and UART are **identical** to Basys3.
