# ZCU104

**Device:** XCZU7EV-2FFVC1156 (Zynq UltraScale+) | **Vendor:** AMD-Xilinx

**Covered:** 300 MHz differential + 125 MHz single-ended PL clocks, 4 LEDs, 5 buttons, 8 DIP switches, USB-UART, Pmod (1.8V LVCMOS).

> ⚠️ Most PL I/O banks run at **1.8V** — use `LVCMOS18`, not `LVCMOS33`.
