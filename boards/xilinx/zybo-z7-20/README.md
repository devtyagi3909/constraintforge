# Zybo Z7-20

**Device:** XC7Z020-1CLG400C (Zynq-7000 SoC) | **Vendor:** Digilent

**Covered:** 125 MHz clock, HDMI TX + RX (TMDS), SSM2603 audio codec (I2S + I2C), 4 LEDs, 4 buttons, 4 switches, USB-UART, Pmod JA/JB/JC/JD/JE.

> ⚠️ **JE header is 1.8V** — must use `LVCMOS18`, not `LVCMOS33`.

> This is the most widely used Zynq development board in university courses.
