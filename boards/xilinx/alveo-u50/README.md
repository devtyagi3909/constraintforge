# Alveo U50

**Device:** XCU50-2FSVH2104E (UltraScale+) | **Vendor:** AMD-Xilinx

**Covered:** 100 MHz differential system clock, PCIe Gen3 x16, 8 GB HBM2 (on-package), 2× QSFP28 (100GbE), I2C management, UART.

> ⚠️ **Data center card** — requires PCIe slot, active cooling. Not a standalone dev board.

> ⚠️ **All I/O is 1.2V or 1.8V** — no 3.3V I/O banks. Use `LVCMOS12` or `LVCMOS18`.

**Primary use case:** ML inference, network packet processing, HPC acceleration, quantitative finance.
