# DE10-Nano

**Device:** 5CSEBA6U23I7 (Cyclone V SE SoC) | **Vendor:** Terasic

**Covered:** 3× 50 MHz clocks, 8 LEDs, 2 buttons, 4 switches, Arduino header, GPIO expansion, HPS UART/Ethernet/SD.

**Files:**
- `de10-nano.qsf` — pin assignments
- `de10-nano.sdc` — timing constraints (include both in your project)
